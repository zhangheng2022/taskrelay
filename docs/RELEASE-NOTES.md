TaskRelay 0.20.0（自签名预览版）

网站设置改为完整管理入口：个人可管理主题、密码与登录会话、站点账号和任务记忆；管理员可管理模型、执行设备、用户、公共执行池及数据保留。电脑使用分类导航与详情双栏，手机从分类列表进入详情，支持刷新和前进后退保留位置。

停用账号或模型会停止相关任务，并将排队和执行中的任务标记为失败；重新启用只用于新交办，不会重试旧任务。已经送出的网站操作不能撤回，仍须核查实际结果。有历史引用、结果未知或待清理锁的资源不能永久删除。

任务记忆仅手动维护，明确启用后用于后续交办；旧记忆默认停用。每次交办固定一份加密快照，规划、执行和云端协助使用同一份偏好；当前要求及后续纠正优先，记忆不会扩大账号、站点或操作授权。修改或删除记忆不改变已有任务快照，快照随任务历史清理。

保存与搜索反馈、编辑冲突恢复、草稿保护和危险操作确认同步完善。改密会撤销其他登录会话并要求重新登录；公共执行池暂停领取不会停止已开始的任务。

执行协议升级至 19，旧执行器需要更新到 0.20.0。保留既有数据、密钥、有效配对及本地 schema 4，更新不会解除吊销或重放历史任务。Windows 沿用自签名和 SHA-256 时间戳；管理员仍需核对并信任公开证书，自签名不保证消除 SmartScreen 提示。真实模型、网站和用户实际设备效果需分别验收。
