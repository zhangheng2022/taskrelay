TaskRelay 0.21.0（自签名预览版）

聊天支持边生成边显示正文。云端交办和执行器回复会先显示“生成中”，正式结果保存后替换草稿；中断内容明确标记未完成。断线重连会读取当前快照，不重新执行任务，上翻历史时保持阅读位置。

模型优先使用 HTTP 流式，分别探测普通文字、工具和结构化输出；已确认不支持时使用同一模型的完整响应。网络失败或业务请求中断不会自动重发，也不会切换模型。工具参数完整并通过校验后才执行，内部推理、摘要、工具参数和 Stagehand 输出不进入聊天正文。

协助前导文字可以预览，最终进入协助时撤下，以原聊天中的正式问题为准。草稿短期加密保存并检查用户、会话和执行权限，清空聊天后拒绝迟到内容。管理员可以分别关闭后续调用的流式和预览，并查看不含正文的耗时与异常指标。

保留既有数据、密钥、有效配对、协议 19 和本地 schema 4；更新不会解除吊销或重放历史任务。Windows 沿用自签名和 SHA-256 时间戳。真实提供方流式兼容性和用户设备上的任务效果仍需按实际结果判断。
