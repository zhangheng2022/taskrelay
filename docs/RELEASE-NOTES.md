TaskRelay 0.19.6（自签名预览版候选）

Windows 主程序、安装器和更新入口增加自签名与 SHA-256 时间戳。受控设备首次部署时由管理员核对公开证书指纹并安装信任；自签名不保证消除 SmartScreen 提示。发布验证覆盖安装包内部与实际安装后的签名，保留 Chromium 等第三方资源原始哈希。

优化网站聊天图片加载：缩略图显示固定尺寸骨架和 Loading，打开大图时先显示缩略图，再切换到原图。缩略图和原图可独立重试，缩略图失败仍可查看原图；当前会话重复打开同一图片复用原图，切图或离开时释放资源。

保留 0.19.4 的跨域账号保存修复。协议保持 18、本地数据库保持 schema 4，本次更新不清空数据；既有有效配对继续使用，更新不会解除设备吊销，也不会自动重放历史任务。

交付增加真实 Chromium 图片验收，继续执行完整 Windows 打包及实际安装验收。网站检查覆盖桌面和窄屏合成图片场景，不代表真实手机、生产网络时延或真实模型网站任务已通过验收。
