TaskRelay 0.19.4（未签名预览版）

修复跨域登录成功后未出现账号保存卡片的问题。卡片由执行器依据实际登录结果提出，不因登录落点与任务入口不同、或访问列表尚未包含当前页而阻止生成。

本人确认后，保存登录落点的 Cookie 和 Local Storage，供后续任务恢复；该关联只用于登录状态，不自动扩展密码投递和业务账号匹配范围。保存卡片生成失败时，原聊天明确提示，并在诊断中记录脱敏域名和固定错误分类。

保留 0.19.3 的页面字段去重和摘要优化。协议保持 18、本地数据库保持 schema 4，本次更新不清空数据；既有有效配对继续使用，更新不会解除设备吊销，也不会自动重放历史任务。

源码回归、包内及实际安装 smoke 分别验收；这些验证不代表真实模型和 Microsoft 网站登录闭环已经完成，实际效果须在更新后复测。
